# Skills

This folder packages the 10 Rules as a [Claude skill](https://docs.claude.com) — so Cowork and Claude Code can install them with a single `/plugin install` command instead of pasting into Custom Instructions.

**Works with:** Claude Cowork mode, Claude Code

---

## What's here

| Skill | What it does |
|-------|--------------|
| [`ai-memory-for-pms/`](./ai-memory-for-pms/SKILL.md) | The 10 Rules for AI PM's — the flagship of this repo, packaged for plugin install |

---

## Install

From inside Cowork or Claude Code:

```
/plugin marketplace add isabela-valonni/easy-ai-pm
/plugin install ai-memory-for-pms@easy-ai-pm
```

That's it. The skill is now available across all your Cowork projects.

---

## Not in Cowork/Claude Code?

Use the paste-into-settings install instead — see the main [README](../README.md#install) for the Claude/ChatGPT/Gemini paths.
